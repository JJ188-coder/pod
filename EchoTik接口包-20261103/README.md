# EchoTik 接口包（2026-11-03）

把 EchoTik（echotik.live）**已购会员的只读接口**整理成一个可直接跑的包：
接口契约、可运行 SDK 与离线自检。

> 适用范围：用自己的会员账号、在自己的浏览器里读自己有权看的榜单数据。
> 不含任何账号密码、Cookie、Token；本包也**不提供**抓别人会话或绕过会员墙的能力。

---

## 三条现状要说清

| 项 | 状态 |
|---|---|
| 已实测可用 | 商品销量榜 `top-sold`、类目元数据 `product-category`，MX 周榜/月榜/前一周各 20 条真实数据（`samples/` 未包含在公开仓库） |
| 只在「复用已登录页面」模式下验收过 | 新进程独立连接曾卡在握手；修好后优先用已有连接模式 |
| 每日会员额度如何折算成分页/请求数 | **未独立验证**，不能当无限调用 |

---

## 30 秒上手

```bash
# 1) 离线自检（不需要登录、不联网）
#    公开仓库未包含 samples/；先放入自己的响应 JSON，否则会提示 SKIP
node check.mjs

# 2) 跑一次真榜（需要浏览器里已登录 echotik.live，且开了调试端口）
node sdk/cli.mjs --period weekly --range 20261012-20261018 \
  --category-path 824328,839944,601226 --country MX --out weekly.json
```

参数含义、返回字段、坑，见 `01-接口契约.md` 与 `02-用法.md`。

## 数据能回答什么问题

- 某类目某周期卖得最好的商品（销量排序，含价格区间、评价数、达人数、带货视频/直播数）
- 同一款商品在不同周期的对比（周/月/前一周）
- 类目 ID 与层级（做筛选参数用）

**不能**回答：库存、成本、实时成交明细、买家信息。这些不在这两个接口里。
