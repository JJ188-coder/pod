# 用法

## 前置：一个已登录的浏览器

SDK 不自己登录，它**复用你已经登录的 echotik.live 页面**。
两种接入方式，按你的环境选。

### 方式 A：复用现有页面连接（已验收）

需要浏览器开了调试端口并能列出 target，例如 Edge/Chrome 的 `http://127.0.0.1:9222/json/list`。
SDK 会找到 `echotik.live` 的页面 target，在页面里刷新一次以捕获正常 UI 请求带的鉴权头。

```bash
node sdk/cli.mjs --period weekly --range 20261012-20261018 \
  --category-path 824328,839944,601226 --country MX --out weekly.json
```

### 方式 B：显式头（自备授权，未在本包验收）

`client.mjs` 支持从环境变量读，**运行时才读，不落盘不回显**：

```bash
ECHOTIK_AUTH="<你自己的会话头值>" ECHOTIK_USER_ID="<你的用户ID>" \
  node client.mjs --period weekly --range 20261012-20261018 --category 824328,839944,601226
```

> 这条路径**没有在本包内验收过**（我们一直走方式 A）。
> 缺变量时会明确报 `AUTH_ENV_MISSING`，不会静默降级。

## CLI 参数

| 参数 | 取值 | 默认 |
|---|---|---|
| `--period` | `daily` / `weekly` / `monthly` | `weekly` |
| `--range` | daily 用 `20261021`；其余 `20261012-20261018` | 必填 |
| `--category-path` | `824328,839944,601226` | 必填 |
| `--category` | 单个类目 ID，可重复 | — |
| `--country` | `MX` / `US` | `MX` |
| `--page` | 1..5 | 1 |
| `--per-page` | 1..20 | 20 |
| `--categories` | 加这个开关则读类目元数据，而非商品榜 | 关 |
| `--out` | 输出文件；省略则打印到 stdout | — |

```bash
# 类目元数据
node sdk/cli.mjs --categories --out categories.json

# 月榜
node sdk/cli.mjs --period monthly --range 20260901-20260930 \
  --category-path 824328,839944,601226 --out monthly.json
```

## Node API

```js
import { EchoTikSDK } from "./sdk/index.mjs";

const sdk = await EchoTikSDK.open({ country: "MX" });
try {
  const page = await sdk.rankings({
    period: "weekly",
    range: "20261012-20261018",
    categoryPath: ["824328", "839944", "601226"],
    page: 1,
    perPage: 20,
  });
  console.log(page.data.length, page.meta.total);
} finally {
  await sdk.close();   // 必须关，否则连接挂着
}
```

## 限速与预算（不是建议，是硬边界）

| 规则 | 值 |
|---|---|
| 每次运行最多新请求 | **5** |
| 请求间隔 | **≥ 1500 ms**，串行 |
| 自动重试 | **无** |
| 自动轮询 / 循环重连 | **无** |

需要更多数据就分多次运行，不要在一个进程里打满。

## 数值解析（必读）

```js
import { parseMetric } from "./client.mjs";
const top = page.data[0];
const sold = parseMetric(top.sale_cnt);        // "1.18万" -> 11800
const gmv  = parseMetric(top.total_gmv_amt);   // "MX$217.89万" -> 2178900
if (sold === null) throw new Error("字段格式变了，先查契约再往下走");
```

不要在业务代码里写 `Number(x)`——字符串里可能带「万」和币种，会静默变 `NaN`。

## 离线自检

```bash
node check.mjs          # 用 samples 校验契约，不联网、不需要登录
cd sdk && node --test test/*.test.mjs   # SDK 单测（14 项）
```

`check.mjs` 会验：字段是否齐全、`product_id` 是否 19 位字符串、价格是否为展示字符串、
`meta` 分页字段是否存在、类目路径是否三级。任何一项不符直接非 0 退出。

## 拿到的数据怎么用（本项目口径）

1. **不要用榜单标题直接上架**：榜单标题堆满营销词，抄了既不合规也难转化。
2. **抄摄影语言和印位比例，不抄商品**：本项目从榜一测出"正面小胸标 13%、背面大图 70%"，
   这条比抄标题有用得多。
3. **周期要标注**：`sale_cnt` 是选定周期的值，写报告必须带周期，否则不可比。
