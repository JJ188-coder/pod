# 安装 4 个插件（5 分钟）

包内 `02-插件/` 就是插件源码，两种装法，任选其一。

---

## 方式 A：从本地目录装（推荐，离线可用）

把整个 `02-插件/` 目录放到本机任意位置，然后在 ZCode 里按插件安装流程指向本地目录：

| 插件 | 目录 | 说明 |
|---|---|---|
| pod-image-listing | `02-插件/pod-image-listing` | 出图到批量上架 |
| pod-galaxy-design | `02-插件/pod-galaxy-design` | 银河建款/上传/读回 |
| tiktok-tshirt | `02-插件/tiktok-tshirt` | T恤 MCP 工具 |
| slack-pattern-receiver | `02-插件/slack-pattern-receiver` | Slack 图案接收 |

装完确认：每个插件目录里有

```
.zcode-plugin/plugin.json  或  .codex-plugin/plugin.json
scripts/ 或 mcp/           （插件入口）
skills/<同名>/SKILL.md     （技能说明）
```

---

## 方式 B：走本地市场

`02-插件/marketplace.json` 是本地市场清单，含 4 个插件指向。把 `02-插件/` 当成市场根，
导入后逐个启用即可。

---

## 装完先验证（别只看"已安装"）

```bash
# 1) 插件入口能被 node 解析（无语法错）
node --check 02-插件/pod-image-listing/scripts/listing-step.mjs
node --check 02-插件/pod-galaxy-design/scripts/galaxy-step.mjs

# 2) MCP 型插件能启动（tiktok-tshirt / slack-pattern-receiver）
bash 02-插件/tiktok-tshirt/mcp/launch.sh   # 能起来再 Ctrl-C
```

MCP 插件要在客户端里**真实调用一次工具**才算接通，`plugins list` 里出现不代表可用。

---

## 依赖

| 依赖 | 用途 | 检查 |
|---|---|---|
| node ≥ 20 | 全部脚本 | `node -v` |
| python3 + Pillow | 出图/合成/自检 | `python3 -c "import PIL;print(PIL.__version__)"` |
| openpyxl | 建批量表 | `python3 -c "import openpyxl"` |
| wrangler（已登录） | 图床部署 | `npx wrangler whoami` |

缺 Pillow 时**不要用 venv 里的 python**（我们踩过 `.venv-kb` 没有 PIL），
用装了依赖的那个解释器跑。
