| 正面 | **13%** 宽 | 小胸标，左胸，下沿在胸线以上 |

### 2.3 单独合成一张

```bash
python3 03-工具/compose-refit.py \
  --base 底图.png --front 正面.png --front-box 33.4,30,38.6,42.24 \
  --back 背面.png --back-box 62.85,30.4,90.15,73.6 --back-fit width \
  --out 输出.jpg
```

`-box` 是画幅百分比，`--back-fit width` 表示按宽度对齐（这才是"大不大"的判定口径）。

## 3. 建上架表

```bash
python3 03-工具/make-spec.py \
  --styles JC001,JC002,JC003 \
  --out spec.json --prefix lote
```

规格：单色 Negro × S/M/L/XL = 4 SKU，123 MXN，每 SKU 5 件，包裹 200g / 15×15×15。

**标题逐款唯一**（`…Modelo {款号}` 收尾）。相同标题会被平台合并成一个商品。

---

## 4. 图床托管

```bash
node 03-工具/publish.mjs --spec spec.json --stage plan \
  --host pages --site-dir "$PWD/.local/pod-images-site" \
  --base-url https://img.bri-king.com --prefix lote --pid <PID>
```

这一步会：拷文件到站点目录 → `wrangler pages deploy` → **逐张验证 URL 200 + 尺寸 + 比例**。
任何一张不合格整体拒绝，不半填。

⚠️ 大文件量时部署可能超过默认超时（我们遇到 `operation was aborted due to timeout`）。
处理：**换成分两次跑**——先 `--stage plan` 只做托管，再用已生成的 URL 走后续阶段。

托管完成后生成「URL 版 spec」：

```bash
python3 03-工具/make-spec.py --styles ... --out spec-url.json \
  --prefix lote --base-url https://img.bri-king.com
```

## 5. 平台预检（不建商品）

```bash
# 5.1 接口级：分析 + pre_check
node 03-工具/publish.mjs --spec spec-url.json --stage precheck --host static --pid <PID>

# 5.2 页面级：页面真去抓图，看到「N 款商品准备就绪」就停，不点导入
node 03-工具/publish.mjs --spec spec-url.json --stage pagecheck --host static --pid <PID>
```

**看这两个数**：
- `product_count`：必须等于你的款数（不等于说明标题撞了，被合并）
- `readyProducts`：页面级预检通过数，等于款数才算过

`pre_check` 的 code=0 **不代表图片能抓到**，图片门以页面级预检为准。

## 6. 分波导入

**每波 25 款，最多 25**。每波之前必须重载批量页：

```bash
# 重载（清掉上一份表的错误横幅）
node 03-工具/goto-batch.mjs <PID>

# 导入
node 03-工具/publish.mjs --spec wave01.json --stage import \
  --host static --pid <PID> --confirm-import
```

`--confirm-import` 是硬门槛，没有它就只打印会被拒。

输出里 `"imported": 25` 才是真的建了 25 个商品；`"readyProducts": 25` 只是准备好了。

## 8. 详情页（1:3）另说

批量表**没有详情图列**。详情只能进商品编辑页的富文本描述编辑器，且：

- 平台只接受 **1:3**（1080×3240），我们按 9 段 1080 拼成母版再切 3 页
- 四版式已定稿：A 米白杂志 / B 暗黑高奢 / C 电商色块 / D 拼贴杂志
- 生成：`python3 03-工具/make-detail-variants.py --spec <json> --variant bloque --out x.png --split-1x3 <dir>`
- 自检：`python3 03-工具/check-detail-layout.py --spec <json>` 必须 `RESULT: PASS`

**已知限制**：编辑器是 ProseMirror，脚本注入的图片保存后会被丢弃（实测连纯文本都被丢）。
四条自动路径都不行，目前只能人工拖拽或原生 GUI 输入。**不要在这个点上花时间做自动化**。
