# 费用、利润与 POD 供货

适用对象：墨西哥 TikTok Shop，目标店 tk-xjcx4623，当前首款范围 MXTMC001 黑色 S/M/L/XL，180G CVC、50%棉50%涤。版本日期：2026-10-23。

本文回答三件事：工厂能不能供、卖家能承诺卖多少、每卖一单到底剩多少钱。单位成本、平台费用、运费和税负是不同层级；任何一层缺失，完整利润就保持 null，不能把空值当 0，也不能拿组件报价冒充履约成本。

## 一、供货判断口径

POD 不等同于预先压一批成品。是否可卖按以下证据判断：

1. 对应款号、颜色、尺码的胚衣当前能否供。
2. 哪些尺码断码、限量或需要排产，何时恢复。
3. 工厂按单生产能力和订单截单时间。
4. 正常生产、包装、交运和承运首扫的时效。
5. 发货仓、工厂实际路由、服务范围和异常订单处理方式。
6. 价格、工艺和印花大版是否适用于该 SKU。

不要求工厂必须给出“成品仓库现有多少件”的精确数字。工厂告诉销售端在某段时间内可接多少单，也可以形成履约额度；这个数量是卖家可售额度，不是仓库实数。

平台若强制填写可售数量，数量应来自可解释的履约额度，不得照教程填 1000。至少保留可供状态、产能依据、时间窗、运输截点和安全余量；未取得依据时，草稿可以继续准备，但不填虚假数量、不发布。

## 二、供货证据卡

每个款号、颜色、尺码分别建一张供货证据卡：

| 字段 | 允许值或内容 | 用途 |
|---|---|---|
| supplier_alias / catalog_id | 工厂别名；目录标识原样保存 | 区分供应商目录与真实工厂 |
| style_code | MXTMC001 或其他真实款号 | 锁定款型 |
| composition | 180G CVC、50%棉50%涤 | 写材质；不改成纯棉或水洗 |
| color | Black / 买家文档 Negro | 锁定颜色 |
| size | S/M/L/XL | 逐码判断，不用总表掩盖断码 |
| blank_supply | available / limited / sold_out / unknown | 胚衣可否供 |
| shortage_note | 哪个码、为什么限制 | 防止“平均有货”误卖断码 |
| restock_eta | 日期或时间窗；没有则 null | 决定是否暂时下架该码 |
| order_capacity | 每天或每周可接单量及计量口径 | 形成履约额度依据 |
| cutoff_time | 当天接单截点与时区 | 防止超时承诺 |
| production_lead_time | 从接单到可交运的时间范围 | 承诺履约周期 |
| handoff_sla | 交承运、首扫的预计时限 | 识别虚假发货风险 |
| route_key | 已核的实际发货仓/路由标识 | 防止目录 ID 冒充 factoryId |
| evidence_source | 正常后台快照、工厂书面回复或对账单 | 可追溯 |
| observed_at / valid_until | 读取时间与有效期 | 防止无限期沿用 |
| physical_stock_qty | 可为 null；仅在真实提供时记录 | 可选信息，不是发布前提 |
| seller_quota | 计算后的卖家可售额度 | 平台数量字段的业务依据 |

状态应加时间。昨日的 available 不能自动证明今天仍可接单；一次空查询也不能推成 sold_out。未知就是 unknown。

卖家额度不是直接把产能乘一个任意系数。宜取当前有效期内各项能力的较小值，再扣留人工审单、售后退换和质量问题所需安全余量：

    计划期可售额度 = min(工厂窗口产能, 包装/出库能力, 承运截单能力, 正常可供状态, 经确认的其他上限) - 安全余量

产能、运输和退换数据没有齐时，不编造最终数字。额度应绑定有效时间和复核人；扩量、换款或旺季前重新核。

## 三、POD 订单履约链

| 环节 | 输入 | 输出 | 继续条件 |
|---|---|---|---|
| 1. 平台订单 | 订单号、商品行、商家 SKU、数量、收件地、应付运费、优惠 | 去重后的订单行 | 订单真实存在，金额和 SKU 未变换 |

| 3. 供货预检 | 供货证据卡、订单数量 | 当前可否接、承诺交运时间 | 对应码仍可履约，未超额度 |
| 4. 工厂生产 | 锁定生产图、工艺、印位、数量和收件要求 | 生产单、付款记录、生产预览 | 仅在已有明确授权时付款或推厂 |
| 5. 质检 | 图案、颜色、码数、印位、外观 | 合格照片与记录 | 图案/尺码/数量一致；异常返工或拦截 |

| 9. 结算复盘 | 平台结算、工厂扣费、物流发票、广告、税 | 真实到账和利润 | 对账完成后再称真实利润 |

### 2. 包装与出库

必须分别记录包装袋/盒、标签、耗材、人工、出库或服务费、仓储/保管费（若有）、再包装或重寄。不能只写“包装费=0”。

供应商原字段 0.18 和 20×35×2 未取得明确单位，也不确定是否含包装，不能直接当 kg/cm；180G 是面料克重，不是单件包裹实重。发布前取得含包装的实际计费重和长宽高，并记录单位和取值时间。

### 3. 净运费与补贴

运费按实际发货路线、包裹计费重、邮编/州和承运模式取数。体积重按承运商当时规则计算，通常要比较实重与体积重并以计费规则为准。

净物流负担建议记为：

    卖家净物流负担 = 实际物流及交接成本 - 买家实付运费 - 已确认平台物流补贴 + 工厂额外交接/偏远附加

同一笔运费不能重复扣。RIIN 或工厂代付的运输费已包含在供货总价时，不要再把同一段平台物流加一次。若使用平台面单，应只记录卖家实际承担的差额。

RIIN “MX 快递查询 0 条”表示没有取得报价，不代表免费；“面单 ALL/CNY=0”也不能证明包邮、物流免费或不收费。出发仓、收件州、计费重、承运和本店资格任何一项不同，都可能改变实际价。

### 4. 平台费用

每个费用字段必须同时记录：

- 费率或金额。
- 计费基数：商品价、优惠后金额、含税/未税、是否含买家运费。
- 作用域：每单、每件、每 shipment 或每次结算。
- 生效时间、账号资格和证据来源。

至少分列佣金、固定/技术服务费、SFP、商家优惠、平台券、活动折扣、买家运费和补贴。每单/每件口径必须以本店账单和当前页面核验，不能因为教程采用某一口径就直接套用。

历史通用口径曾核为佣金 6%、固定费 6MXN，SFP 8% 且每件封顶 40MXN；用户本次截图又把 6MXN 写在“每单”，所以本店究竟按单、按件还是多件单分摊仍需当前账单证据。P 为售价，参与 SFP 且未触发封顶时，可写 SFP=P×8%；不可见优惠也可改变计费基数。

### 5. 达人、广告与推广

达人佣金、寄样成本、广告消耗、活动折扣和素材制作费分开。达人佣金按成交支付，不等于广告预算；广告只来自明确批准的预算。不能用“自然流量假设 0”证明真实获客成本为 0。

### 6. 售后与损耗

记录退款、退货、重寄、破损、错码、图案瑕疵、平台赔付、优惠补偿和无法二次销售的损失。新阶段没有历史售后数据时，可以设明示的压力情景，但该金额是预算假设，不能冒充真实成本。

### 7. 汇兑与支付

采购用 CNY，销售结算用 MXN，必须记录实际购汇/结汇价、支付通道费、平台提现费和时间差。ECB 或公开汇率只能用于横向比较，不能冒充到账汇率。

### 8. 税费与代扣

平台代扣 IVA/ISR 是结算现金流之一，不等同于最终税务利润。本店是否适用 8% IVA、2.5% ISR 取决于 RFC、注册地址、交易类型和当期规则；当前没有本店税务证据。

税务模型应单列：

- settlement_withholding：结算时实际预扣或代扣。
- final_tax_adjustment：最终申报和汇算后的补/退税。
- tax_credit_or_rebate：可抵扣或有条件的返还款。

不得把预扣额和最终税负同时重复扣减。税务判断应以墨西哥会计/税务专业意见和平台账单为准。

### 9. 固定成本分摊

工具订阅、人工、摄影、电脑和设计费用可按批或按月归集。早期可以暂不计入单件经营贡献，但必须在利润桥中单列，不能永久默认 0。

## 五、三个利润视角

同一个数不能同时承担“可用现金”“经营贡献”和“会计净利润”三种职责。

### 1. 税前经营贡献

用于判断一次正常成交能否覆盖直接变动成本：

    经营贡献 = 卖家优惠后的商品收入（扣平台费用前）
             - 原衣及印花组件
             - 大版/双面/工艺附加
             - 包装与出库
             - 卖家净物流负担
             - 平台实际佣金和固定费
             - SFP等服务费
             - 达人佣金和广告
             - 售后与汇兑损失

此处收入起点不预扣平台费用，再在后续逐项扣费；要按平台实际计基方式处理优惠和运费，不能只用商品标签价简单相乘。任何一个必需成本为 null 时，经营贡献也应为 null；“未知成本预算”另列，不塞进 0。

### 2. 代扣后可用现金

若“平台实际结算到账”已经是扣除平台费、优惠和代扣税后的净额：

    代扣后现金 = 平台实际净到账 - 已付供货 - 已付包装/物流 - 已付广告 - 其他实际支出

若手头只有优惠后、扣费前的成交额，则另用完整桥表：

    代扣后现金 = 成交额 - 平台实际费 - 代扣税 - 已付供货 - 已付包装/物流 - 已付广告 - 其他实际支出

两种起点不能混用；已经净额到账时不得再减一次代扣税。它帮助判断短期周转，但不能直接当本期利润。预扣税未来可能调整，增值税和所得税也不能混为一谈。

### 3. 会计净利润

    会计净利润 = 确认收入 - 对应成本/费用 - 最终税负 + 应计调整

收入确认、VAT 抵扣、期间费用和税负需按会计口径处理。没有工厂扣费、平台结算、物流发票和税单，真实净利润写 verified_profit=null。

### 4. 未知成本预算

允许做“售价目标反推”：

    可用未知成本预算 = 售价 - 已知直接成本 - 目标利润

该预算用于判断还剩多少空间覆盖包装、物流、税和售后，不等于成本已经为 0。发布时要把未知预算写成范围和适用假设，并做至少正常、偏高运费、含售后的情景。

## 六、截图表公式复核

用户提供的截图公式口径如下，P 为 MXN 售价：

    1MXN = 0.39CNY
    cost = 14 / 0.39
    佣金 = P × 6%
    SFP = P × 8%
    IVA = P ÷ 1.16 × 8%
    ISR = P ÷ 1.16 × 2.5%
    表内利润 = P - 佣金 - SFP - IVA - ISR - cost

截图算式遗漏了额外 6MXN；如果该 6MXN 按本店实际规则应扣，应另减，但按单、按件或多件单分摊仍待平台账单确认。P=68MXN 的复算为：

## 十、异常与处理

| 异常 | 处理 | 恢复条件 |
|---|---|---|
| 工厂不显示库存数字 | 不要求虚构成品库存；改核逐码胚衣可供、断码、产能和时效 | 有明确状态、时间窗和履约额度依据 |
| 某个尺码断码 | 暂停该尺码售卖或按真实补货时间处理 | 工厂确认恢复，重新记录时间 |
| 库存显示 *** | 视为未知，不当 0 或无限 | 正常权限恢复或工厂给出能力依据 |
| 只能拿到组件价 | 不发布最终成本广告，不把组件价当完整价 | 取得印花、包装、出库和物流最终报价 |
| 大版/面积报价为空 | 1 图 2CNY 保持组件价，不计最终生产通过 | 工厂给出面积档或明确包含关系 |
| 快递或图片价格查询 0 条 | 记 unknown 和原请求上下文，不记免费 | 正常接口返回可适用报价或工厂实际账单 |
| 面单金额为 0 | 只说明该字段为 0，不推成包邮 | 有真实物流/补贴依据 |
| 平台费率与教程不同 | 以本店当前规则和账单为准，保留生效日期 | 费用字段全部有基数与作用域 |
| SFP 与整笔运费同时被扣 | 回查实际账单；SFP 是服务费，不能重复替代同一笔运费 | 净运费和 SFP 分开列示 |
| 一笔订单多件 | 逐件算商品/印花，按平台确认的作用域算佣金和固定费 | 作用域和计基已核，重算利润 |
| 退款/重寄 | 从对应订单扣回收入与成本，更新售后准备 | 实际退款、赔付和重寄记录完整 |
| 汇率变化大 | 以实际付款/结算汇率重算，不用截图汇率和 ECB 混算 | 现金流能按真实到账解释 |
| 截图利润为正就等于赚钱 | 补 6MXN 和全部缺失成本后再判断 | 所有关键费用通过验收，真实利润另行确认 |
| 想批量填 1000 或直接扩链接 | 停止；按额度、规则和授权另行批准 | 有供货能力和链接/发布授权 |
