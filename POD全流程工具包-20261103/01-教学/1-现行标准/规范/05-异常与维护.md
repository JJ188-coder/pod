# 异常、重试和维护

| 现象 | Agent处理 | 恢复条件 |
|---|---|---|
| GPT图案变样、位置/比例改变 | 该任务退回；生产图保持锁定，重新用准确参考生成并逐图比对 | 完整构图、可见比例、色码与印面一致 |
| 字体错字/伪西语 | 文案从es-MX清单复核，修素材，重新冻结 | 图中文字和标题详情一致 |
| 某码越界 | 调该码排版；记录物理尺寸/坐标；若改生产版升revision | 银河逐码回读通过，不凭其他码推断 |
| 冻结后任何文件改变 | 校验失败即停止本批新写入；回素材段重新审阅/冻结 | 新指纹与审阅记录一致；旧冻结留档 |
| 文件存在但打不开 | 重生成/恢复真实原件，不只改扩展名 | 实际图片解码成功、尺寸满足当前页面 |
| 工厂不显示库存 | 按POD判断胚衣可供、断码与产能，不要求成品库存表 | 可供/时效依据支持本批销售额度 |
| 工厂权限/验证码/限额 | 停对应接口、保留精确错误，继续本地独立工作 | 正常权限恢复，不绕过、不无限重试 |
| 银河任务保存后换ID | 新旧任务ID与生产版关联，更新overlay | 所有SKU能反查当前真实任务，不靠推算 |
| 保存后字段丢失 | 用正常输入/上传事件与保存，等结束，真实重开读回 | 平台读回一致，不以原DOM值报成功 |
| 同款20套不符合多链接条件 | 保留素材用于同一商品图测/合规变体，不创建重复链接 | 真实差异、规则和数量授权明确 |
| 费用空表/运费未返回 | 标null，保留上下文与模板ID；查正常后台 | 实际适用依据明确；不将空表记免费 |
| 重试失败 | 图像单任务最多1次自动重试（含首次最多2次请求），后停该任务；认证/权限错误立即停 | 诊断并修正原因后有界恢复 |

## 任务状态和恢复

队列状态依次为planned、running、generated、reviewed、failed。planned没有图片，generated不等于检查通过；后台没有启动时不写running。恢复时只处理未完成任务；同任务ID已有经检查文件和SHA256则复用，不重复出图浪费额度。多个Agent不能同时写同一任务。

## 资料维护

批次清单保存输入、输出、审阅、实际任务ID、时间、错误和恢复位置。素材冻结之后的平台返回数据写overlay，不改变已冻结文件。重新冻结保留旧版本，以免历史订单失去原图。

新业务决定在真实来源记录后主动登记统一知识库；后续报价、费率与模板变更另开生效版本，不能仅凭文件mtime认为新价格已生效。删除旧图前查历史订单及映射，默认保留。

检查工具只做离线预检，不承担访问控制、收费、工厂验证或实际发布。执行者仍须核真实证据，不能通过手改布尔字段把业务缺口伪装为已核。
