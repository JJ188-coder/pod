# 素材生产、批量出图与整批冻结

适用对象：墨西哥1号工厂 T 恤，当前范围为 tk-shop-a、MXTMC001 黑色 S/M/L/XL、180G CVC、50%棉50%涤。新款必须重新核对自己的款号、颜色、尺码、面料、印面和工厂规则，不能照抄首款数据。

版本日期：2026-10-23。本文定义生产图、批量视觉、es-MX 上品素材与本地冻结方法；文中“已保存”“已冻结”不表示已获工厂适印、已上传平台、已提交审核或已发布。

## 一、先分清五种对象

| 对象 | 本项目定义 | 会改变什么 | 不会改变什么 |
|---|---|---|---|
| 生产图版本 | 例如 SJBLUE-R01-F，决定衣身上真实印什么 | 商品实物、生产文件、订单映射 | 不能因为背景或模特换了就改变 |
| 视觉方案 | 例如 V01–V20，是拍摄场景、角度和版式 | 主图、详情、情境表达 | 不自动产生新商品或新 SKU |
| 胚衣 SKU | 例如 MXTMC001-Black-S | 厂款、颜色、尺码 | 不能由视觉编号推算 |
| 平台对象 ID | 银河任务、商品草稿和 SKU ID | 线上实际对象和路由 | 不能由业务编码反推或伪造 |
| 上品批次 | 例如 B20261023-SJBLUE-01 | 一次可审阅、可冻结的交付范围 | 不等于获得生产或发布授权 |

同一实物只用背景、模特、标题或裁切方式做出多个版本时，身份仍是同一实物商品。是否可以形成多条商品链接，必须先核当店规则、真实商品差异和数量授权。当前只有已存在首款的单品发布授权，未扩大为 10–20 条链接或批量发布。

## 二、批次输入与输出

没有以下输入，不创建“可运行”的出图任务；缺项只能停留在 planned 或 blocked，不能用合理想象补全。

| 输入 | 至少记录 |
|---|---|
| 批次与范围 | batch_id、目标店、工厂、款号、颜色、尺码、计划上品数量 |
| 商品事实 | 180G CVC、50%棉50%涤、领型、袖型、实际颜色、可售范围 |
| 生产图 | design_id、revision、前/后印面、原始文件、权利来源、版本说明 |
| 印花几何 | 每码可见图案宽高 cm、坐标、印面、模板依据、有效像素与有效 DPI |
| 视觉计划 | 10–20 个视觉方案及用途、比例、文案、SKU范围 |
| 西语资料 | es-MX 标题、卖点、详情、颜色名、尺码称呼和图中文字 |
| 尺码数据 | 每码衣长、整圈胸围、肩宽、袖长，明确 cm 与成衣口径 |
| SKU 预映射 | 商家 SKU、胚衣 SKU、生产版本、印面、尺码、视觉包一一对应 |
| 费用与供货 | 可从 04 规范引用；未知项保持未知，不阻断本地素材制作，但阻断发布 |
| 授权 | 本次允许生成、上传、建草稿或发布的范围与数量 |

每批输出至少是一份 batch manifest、锁定生产图及其 SHA-256、10–20 个视觉任务的可追踪记录、实际解码通过的图片、es-MX 文案、尺码图、逐 SKU 图、审阅记录和冻结指纹。任务写入队列不等于生成完成，生成完成也不等于审阅通过。

## 三、生产图先锁版

### 1. 最新印花边界

| 尺码口径 | 用户给定每面最大值 | 按 PSD 主框 19:25 收进后的设计框 | 性质 |
|---|---:|---:|---|
| 3XL | 36 × 56 cm | 36 × 47.37 cm | 用户业务口径；设计框为等比计算 |
| S，约为 3XL 宽高 80% | 28.8 × 44.8 cm | 28.8 × 37.89 cm | 近似设计口径，不是逐码机台实测 |

PSD 主框约 38 × 50 cm、比例 19:25，与 36 × 56 cm 不是同一比例。M/L/XL/2XL 的最新精确厂规没有取得，保持 null，不按经验编成正式表。原 29.5 × 44.5 cm 图宽超过新 S 上限 0.7 cm；只按最大值等比收入时为 28.8 × 43.44 cm，严格按 PSD 主框比例收入时为约 25.12 × 37.89 cm。图案自身必须等比缩放，不能拉宽或压扁去填满框。

模板可容纳、银河预览显示“正常”和工厂可生产是三件事。只有工厂给出适用于该款、该颜色、该尺寸、该印面和该图幅的实际适印依据，才能把生产适用性写成已核。

### 2. 生产图文件卡

每个生产图 revision 必须记录：

- design_id、revision、print_side、适用款号与颜色。
- 原件路径、文件类型、文件大小和 SHA-256。
- 画布像素、透明边界内可见图案像素、透明空白范围。
- 每个计划尺码的可见宽高 cm、坐标、缩放比例和计算 DPI。
- 权利来源：原创、用户提供、明确授权或其他可核来源；不得把竞品商品图自动当作可生产素材。
- 制图时间、制作人/Agent、使用的工具和参数、审阅人和审阅结果。
- production_ready、factory_print_ready、rights_ready、geometry_ready 分开记录。

有效 DPI 按“可见图案像素数 ÷ (计划可见宽度 cm ÷ 2.54)”计算。PNG 元数据写着 300DPI，不能证明像素细节足够；插值放大或修改 DPI 标签也不能把低清图变成高清图。项目 150DPI 复核线是内部检查线，未取得工厂书面规则前不得冒充厂规；若工厂接受更低值，必须记录具体源图、尺寸和工厂依据。

当前首款生产候选仍受大版清晰度与工厂适印证据约束。已有 24.70 × 37.87 cm 的 S 码银河记录只说明一次已存布局，不批准所有尺码，也不证明高清生产文件已通过。

### 3. 锁版规则

进入批量视觉前，先冻结 production_ref。后续主图、背景、模特或标题变化只能引用该 production_ref，不能重新绘制图案细节。

生产图的可见构图、文字、色块或印面发生变化，必须升生产 revision，并重做全部衍生图、全部 SKU 映射和冻结校验。背景、光线、镜头角度或文案位置变化可升视觉 revision，但不得触碰生产图版本。

## 四、单款 10–20 套视觉方案

### 1. “一套”是什么

一套视觉方案是一个有明确用途的成组资产，包含场景/角度、锁定生产图引用、构图规格、es-MX 文案、计划交付图、替代裁切以及审阅状态。一个方案可以派生多个比例裁切，但同一源图不能在不同用途重复计数来凑 20 套。

常规单款视觉策划可规划10–20套；首款接管或单链接试跑可以独立采用1套批次，不为凑数量重复出图。批次计划数一旦冻结，计划内每个必需套件都要达到 reviewed，不能挑已完成的一半就宣称整批完成。若实际业务只需 12 套，应在开跑前把另外 8 套标成明确 excluded 的理由；不能等失败后抹掉任务来制造完成率。

## 五、批量出图队列

### 1. 队列位置与任务字段

统一队列入口为 T恤/数据/GPT批量出图任务.json，机器字段以批次 manifest 和校验工具当前版本为准。每个任务至少保存：

- job_id、batch_id、set_id、V 编号、用途、目标比例和输出规格。
- production_ref、production_asset_sha256、印面和 SKU 范围。
- 参考商品图、胚衣模板、构图说明、prompt_version、完整提示词。
- 工具类别、模型/接口标识、参数、seed（若接口支持）、开始与结束时间。
- 输出路径、文件 SHA-256、实际像素、解码结果和文字校对结果。
- status、attempts、失败类别、错误摘要、恢复条件和审阅记录。

工具支持 seed 时记录 seed；不支持时记录完整参数和输入指纹。所有文件按 job_id 和 set_id 可反查，不能只留一串无法辨认的临时文件名。

### 2. 状态机

任务状态沿用 planned → running → generated → reviewed；失败为 failed。batch 级状态另行记录 materials_ready 和 frozen。

- planned：只完成计划，没有请求模型，不占“已生成”数量。
- running：已有真实请求正在执行，记录请求时间和并发槽。
- generated：已落盘并计算指纹，但尚未通过人工/程序审阅。
- reviewed：图像、构图、图案、es-MX 文字、裁切和用途均通过。
- failed：技术失败或输出验收失败；记录原因，不能只写“重试”。
- materials_ready：所有计划必需素材已 reviewed，等待冻结校验。
- frozen：manifest、任务、文件指纹与审阅记录一致，已形成不可变快照。

“已排队”“已生成”“已检查”“已冻结”“已存草稿”“已发布”必须分别记录。当前只建立规范与队列契约；本次没有启动后台批量、没有新增生成图，0 张生成不能写成 running。

### 3. 并发、失败与成本控制

- 初始并发为2，由Agent根据当前工具能力与已授权预算安排；普通技术调度自行处理，新增费用或扩大业务范围另核授权。
- 单任务最多执行首次生成和 1 次自动重试，共 2 次尝试；不得做第 3 次盲试。
- 连续 2 次技术失败时暂停派发新任务，等待现有运行槽结束。Agent 诊断并修正原因后，可在原授权、原并发和原预算内做有界恢复，不因普通并发或恢复另行要求业务负责人批准。
- 输出内容未通过审阅属于素材失败，不得以原提示词机械重试；修正参考、提示或版式后再进入有界尝试。认证、权限、验证码、额度耗尽或账号风险提示仍立即停对应入口。
- 只使用当前真实可用且已授权的原生 GPT 图像工具或既有授权 API。不自动购买套餐、积分、加速额度或新图像服务，不因建队列产生费用。
- 恢复只重启未完成的应派任务；已经 reviewed 的复用。新增付费或扩大业务任务范围仍需相应授权；技术并发调整不得突破既有预算与工具限额。

### 4. 生成与锁版图的关系

优先让图像工具生成不含图案的黑色胚衣或生活场景，再用锁定生产图按固定位置和比例合成。若工具直接生成带图案的成品图，该图只能作候选；必须逐项核图案元素、字形、线条、颜色与母版一致，否则不得进入买家图库。

推荐流程如下：

1. 读取 production_ref 和 SHA-256，确认已锁版。
2. 按 set_id 组装输入：锁定图、款型参考、场景要求、西语文字清单和排除项。
3. 生成无图案基底时，记录合成用的 scale、x/y、旋转与透视参数；合成后的图案仍要回到母版核对。
4. 生成带图案图时，对图案做局部对照；任何重绘、字母变形、缺笔或镜像异常直接 failed。
5. 生成图只作为视觉示意图；不得在内部或买家页面标注“工厂实拍”“现货实拍”。
6. 文字尽量用版式本地排版。AI 图中出现伪西语、重音错误或大小写错误时，该图不通过。

### 5. Prompt 基线

每套任务使用可追溯的提示词模板，至少写明：

- 商品身份：MXTMC001 风格黑色圆领短袖 T 恤，墨西哥 1 号工厂候选，50%棉50%涤，180G CVC。
- 生产图引用：准确复制锁定生产图，不新增、不删减、不改字、不换色、不镜像、不重绘。
- 服装事实：真实黑色、正确领型、袖型、衣长与可见印位；没有未核白边、刺绣、水洗或特殊工艺。
- 场景：与 V 编号一致，一个人物或中性静物为主体，不堆无关道具。
- 目标市场：墨西哥成年买家，自然光、可实现的商业摄影质感。
- 文字：画面文字逐字给 es-MX 源文；无法准确生成时留空，由版式层添加。
- 排除项：竞品 Logo、名人肖像、品牌图形、虚假销量、虚假折扣、错误面料和未经核实的性能。
- 输出：明确比例、像素、背景和安全边；图案不挤压、不超出安全区。

## 六、图片审阅标准

### 1. 通用验收

- 文件真实存在、可解码，格式和像素符合当前页面要求；扩展名正确，不是 0 字节或损坏图片。
- 首图和详情能看清商品；黑色没有漂成深灰或白色，领口、袖口、肩线自然。
- 锁定图案的元素、文案、颜色和比例与母版一致；不得出现生成器补画的装饰或缺失笔画。
- 人物手、脸、牙齿、肩线和衣服褶皱自然；无明显拼接、重复肢体或穿模。
- 图案位置符合该尺码计划；没有明显越出模板边界或扭曲到印面外。
- 无模板线、尺寸标注错位、白色透明棋盘格、占位符、残字、水印和竞品标识。
- 图中西语重音、名词阴阳性、尺码写法与标题详情一致。
- 同一批内光线和色温可比，不能一张白底一张暖黄导致黑色看起来像两种颜色。
- 生成图和合成图都保留内部来源标记；买家文案不把示意图冒充工厂照片或真实成交素材。
- 涉及 AI 内容是否需平台披露、主图是否允许场景图和具体比例，发布前按当店当前规则再核，不能只凭本文。

### 2. 通图、详情、尺码和 SKU 的交叉校验

- 图库、详情、尺码图、SKU 图使用同一个 production_ref 和同一批次事实。
- 尺码图四码四指标与原生尺码表逐项相同；胸围是整圈，不是平铺半圈。
- 黑色在本店买家可见颜色选项写Color=Negro，银河/供应商系统码为Black；颜色图片和 SKU 一一对应。
- 每个 SKU 的商家 SKU、胚衣 SKU、尺码、视觉包、生产图和价格引用能往返查找。
- 背面若为空白，详情直说单面；不得用空白模拟图冒充已核工厂背部版型。
- 包装、赠品和售后图仅在事实已核时进入买家页面；否则只保留为 planning_only。

## 七、整批检查和冻结

### 1. 冻结前步骤

1. 从队列取出本批计划；20套策划与首款1套接管分别使用自己的批次范围，所有必需槽位、SKU范围与排除理由清楚。
2. 逐任务检查状态。仍有 planned、running、generated 或 failed 的，不进入冻结。
3. 核对每个 reviewed 文件的路径、SHA-256、像素、解码结果和 production_ref。
4. 核对 es-MX 文案、标题、详情、四码尺码表和逐 SKU 图；用文本差异检查避免一处改了、另一处未改。
5. 核对 SKU 预映射：每个平台计划行只能指向一种真实实物组合，同时允许同色同图案的不同尺码共用视觉示意。
6. 运行当前版本的批次校验命令，以批次 manifest 为准；首款检查路径为 T恤/批次/B20261023-SJBLUE-01/manifest.json。
7. 把校验结果、审阅记录、生产图指纹和素材快照写成冻结记录。

当前预期命令形式为：

    python3 T恤/工具/批次校验.py check T恤/批次/批次号/manifest.json

冻结记录至少包含：

- batch_id、scope、时间、状态和冻结人/Agent。

- 素材冻结不等于银河通过、工厂可供或允许发布的三项明确声明。

冻结后文件或文案任何变化都使本批指纹失配。生产图变化升 design revision；背景或文案变化升视觉 revision。旧冻结保留归档，不覆盖历史，确保已有订单和平台读回仍能追溯原生产图。

## 八、异常与回退

| 异常 | 处理 | 恢复条件 |
|---|---|---|
| 生产图不清或图案重绘 | 停止该视觉批次；不得用插值或 PNG DPI 元数据过关 | 取得合格真实源图，或改动业务方案后重新审阅 |
| S 或某码插图越界 | 只调该码几何并留档；若影响可见生产图，升 revision | 该码银河预览与工厂模板依据一致 |
| 生成图改变图案 | 任务 failed；生产图不随之变 | 用锁定母版重新合成或重新生成候选并逐项对图 |
| 伪西语、错重音 | 图像退回，修改源文或版式 | 与 es-MX 主文案逐字一致 |
| 文件打不开 | 回到真实原件，不只改扩展名 | 解码、尺寸、色彩和透明边界实测通过 |
| 连续两次技术失败 | 暂停新任务，保留完成项 | Agent定位修复后在既有授权与预算内有界恢复 |
| 权限、验证码或额度 | 立即停对应入口，不无限重试 | 正常权限恢复；未知问题不得用绕过方式解决 |
| 计划超过 20 或不足 10 | 调整业务计划，不硬凑或虚报套数 | 10–20 套有真实差异且全部有明确定义 |
| 同品想裂变成多链接 | 保留为同商品素材或候选，查当店规则和真实差异 | 有明确链接规则及对应数量授权 |
| 文案变了但图片没变 | 仍视为冻结失效 | 重新审阅、重新校验、重新冻结 |

## 七、来源素材采集路径（2026-10-30 更新）

EchoTik 商品页只给公开图集（实测 7–9 张、800px、无描述、无属性、无 SKU、无价格）。完整来源素材必须经 EchoTik 记录的原商品链接到 TikTok 商品详情页（PDP）采集，EchoTik 只作为选品与索引层。

### 1. 采集步骤

1. 打开 EchoTik 商品页，读取页面数据里的 `product_url`（形如 `https://www.tiktok.com/shop/mx/pdp/<商品ID>/<商品ID>`）。页面上的“原文”按钮不一定能点出链接，直接读该字段更可靠。
2. 在已登录或公开浏览器打开该链接，会跳转到 `shop.tiktok.com/mx/pdp/...`；实测公开可读，不需要登录。
3. 从页面采集：完整 es-MX 标题、商品描述全文、属性表、颜色与尺码列表、当前价与原价、店铺与公司信息、评分与评价数、买家实拍图。
4. 收集页面全部图片地址，按图片 ID 去重计数（实测同一款 EchoTik 7 张，PDP 41 个不同 ID）。
5. 取图时不要把页面默认尺寸当原图：把 CDN 地址里 `~tplv-...-resize-webp:<宽>:<高>.webp` 的宽高段改为 `1200:1600`，其余签名参数（`dr/t/ps/shp/shcp/idc/from`）原样保留，可得原图尺寸；继续放大到 2400 或 4000 若返回同一字节数，说明已达原始上限。实测该款原图为 1145×1374，而非页面显示的 800×960。
6. 解码确认实际像素后再写入 coverage，不得只按文件大小推断。

### 2. coverage 字段的通过口径

| 字段 | 通过条件 |
|---|---|
| public_gallery | 图集张数与去重后的图片 ID 数一致，逐张记录 SHA-256 |
| main_image | 已确认哪一张是首图；若只按图集顺序取第一张，必须写成“按顺序取首图”的弱口径，不得写成已确认 |
| description | 取到 PDP 上的描述正文，非空 |
| sku_images / sku_prices | 取到 PDP 的颜色、尺码与价格；取不到就保持 unavailable，不得留空冒充已采 |
| tiktok_direct | 已实际打开 PDP 才算 collected；只读 EchoTik 一律记 not_collected |

### 3. 分辨率不是采集通过线

来源原图实测普遍只有约 1145×1374（部分仅 800px）。该尺寸出 4096 长边印花必须放大重绘，放大倍数要在素材卡里写明。采集通过的判据是“图、描述、属性、SKU、价格齐全且逐张可核”，不是“够 4K”；够不够印花属于生产图锁版与视觉审阅环节的判定。

### 4. 禁止事项

不得按文件名或搜索结果批量取图；不得把 EchoTik 封面当印花原图；不得因为 PDP 有买家实拍图就当成官方主图或生产依据；不得跳过 SHA-256 记录直接把图放进生产目录。
