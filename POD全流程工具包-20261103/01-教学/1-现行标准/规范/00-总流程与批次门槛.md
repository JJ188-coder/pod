# T恤从准备到上品：完整执行流程

适用：墨西哥1号工厂、tk-xjcx4623，首款MXTMC001；新款先核自己的款号、工厂和尺码，不照抄首款数据。目标是每个订单能准确指向胚衣、生产图、印位和费用。

## 先把工作分成两段

**素材段**完成生产图、实物规范、所有图片、西语、尺码、SKU和费用计划，落到本地。**上品段**只使用已冻结的材料，去银河验证实际设计和路由，再填店铺字段与保存读回。进入上品段后如果发现素材错误，退回素材段、升版本、重新检查；不临时改图并继续提交。

| 步骤 | Agent具体操作 | 交付与继续条件 |
|---|---|---|
| 01 接单与查库 | 确认目标店、厂、款、图案权利来源、平台时效要求，复用历史成果 | 批次号、范围、现有任务/草稿清单 |
| 02 胚衣与履约 | 核码色可供、断码、按单产能、生产及首扫时效、路线 | 可供依据或明确缺项；不要求成品库存数 |
| 03 生产图锁版 | 保存原图，量透明边界内实际图案比例；排每个尺码/印面 | 不拉伸、不用改DPI冒充高清；尺寸表和SHA256 |
| 04 预先编码 | 图案版本、印面、色码、尺码、视觉版本和链接计划分开 | 业务码能往返解码，预映射完整；平台ID未知保留空 |
| 05 批量素材 | 生成计划中的主图/场景/近景，复用匹配胚衣的通图、尺码、SKU图 | 不是提示词完成就算出图；本地文件实际可解码 |
| 06 西语与表格 | es-MX标题详情、成衣尺寸、颜色、数量、SKU、售价方案 | 图文与真实商品一致；厘米与整圈胸围明确 |
| 07 全批验收 | 逐图看实物一致性、印花比例、颜色和文字，核文件/引用/映射 | 任一计划交付链接缺必需素材，整批不放行 |
| 08 冻结 | 写清单、生成文件指纹和审阅记录 | 批次materials_ready且工具freeze成功；改动即失效 |
| 09 银河预检 | 用冻结生产图，逐码前后面预览、保存，再读回尺寸/打印图/真实ID | 平台任务与印位真实对应；适印/加价缺口在此解决 |
| 10 业务放行 | 验胚衣供货能力、实际路由、适印、完整成本及链接合法性 | 非零可售额度有依据，利润按可信情景接近1USD；未知项明列 |
| 11 店铺上品 | 使用冻结包和银河返回的映射填每个字段 | Color/Talla、逐SKU图、真实编码、价格、重量尺寸等匹配 |
| 12 保存重开 | 等保存成功后，真实新document重开，滚入详情懒加载区 | 图库、详情、SKU、尺码、售价逐项读回一致 |
| 13 提交与状态 | 核对当前授权店/动作/数量，提交后读平台状态 | “提交审核”与“在售”不同，记录真实状态 |
| 14 出单闭环 | 订单去重、映射回厂、首扫、妥投、售后、结算 | 付款和推厂核对应授权，实收利润回填，之后才扩量 |

## 三种放行分开记录

- **素材冻结**：文件、文案、尺寸、SKU预映射与视觉审核齐；可以进入银河预检，不等于批准生产或发布。
- **银河/供货放行**：每码印花预览、适印、真实路由与生产服务确认；不是界面显示“质量正常”就算实物通过。
- **发布放行**：上述完成、费用方案可接受、可售额度有依据、链接规则核实、授权覆盖本次动作和数量。

检查工具只核本地可观察条件，不是平台后台自动化，也不会证明本店费率或工厂能力。生产清晰度按工厂真实要求判断，项目150DPI复核线不是已确认厂规；若工厂明确接受低于此线，记录具体源图、物理尺寸和书面/平台依据再放行。

## 一款10–20套素材怎样使用

先生成20套可比的视觉策划，不立即建20个商品。同一实物的背景/拍摄角度/排版变化默认是素材测试。需要多商品链接时，逐条核对实际商品差异及当店规则；不靠近似标题、换背景或无关SKU掩盖同品。未取得相应资格和授权的候选继续保存在本地，已授权的首款可单独作为1个批次推进。

20套候选与待发布1套使用不同批次清单：不能挑出半批就把20套标成整批完成，也不能因19套候选未生成而否认已有首款资料。
