# T恤视觉与上架标准工作流（2026-11-02 定稿）

本文件是**已确认可执行**的流程定义。凡与本文件冲突的旧做法，以本文件为准。

---

## 0. 一句话架构

**EchoTik 爆款参考 → 生产 PNG → 银河六色效果 → 视觉包（10主图/5详情/6色SKU母图）→ 批量表导入 → 商品ID → 详情插图 → 保存重开 → 银河SKU关联**

---

## 1. 采集：爆款参考

- 入口：EchoTik 商品库，类目 `男装与男士内衣/男士上装/男士T恤`，筛选「近7天动销」。
- 每个爆款记录：商品 ID、店铺、标题、价格、近7天销量/GMV、总销量、**首图原图**。
- 逐张拆解并写入款档案：摄影形式（挂拍/平铺/单模/双模）、人物站位、主体占比、裁切、光线背景、印花展示方式、信息顺序、详情版式。
- 复刻规则：**抄摄影语言，不抄商品本身**。价格、成分、尺码、品牌一律不得沿用参考商品。

2026-11-02 榜一样本：`Playera San Judas Tadeo`（PINTURAMX），男女双模特＋墨西哥殖民街景。参考图存 `.local/pod-refs/`。

## 2. 生产图：Slack 原件

- 来源：指定 Slack 私信交付的 PNG，用 `salck` 插件接收。
- 必须记录：前后片、像素、alpha、SHA-256、原消息绑定。
- 长边不足 4K 时如实标注，**不得称原生 4K**。

## 3. 银河：六色建款（关键修正）

- **一号厂 MXTMC001 声明六色：黑、白、宝蓝、红、粉、绿**。建款必须按六色 × 四码建，不得只做黑白两色。
- 杏色、玫红不在 1 号厂颜色声明内，不建、不卖。
- 建款后保存一次、正常重开，读回每个 SKU 的打印编码与效果图。
- 效果图按 `可售_{Color}_{F|B}_*.jpg` 落盘，供后续 SKU 母图使用。

现状：188 款里只有 6 款（JC002/JC046/JC049/JC101/JC108/JC118）做过六色；其余 182 款需要补建四色。

## 4. 视觉包（核心交付）

每款产出：**10 主图 + 5 详情 + 每启用色 1 张 SKU 母图 + 尺码图 + 上传顺序与 SKU 对应表**。

### 4.1 主图 H01–H10

| 编号 | 任务 | 依据 |
|---|---|---|
| H01 | 首图：男女双模特，男左正面、女右背身回眸 | 爆款摄影形式；墨西哥审美（女模曲线饱满、浅蓝牛仔、发髻不遮背图；男模深色牛仔、银十字项链） |
| H02 | 另一色双人 | 同上 |
| H03 | 背面大图特写 | 银河后片效果 |
| H04 | 图案细节 | 真实生产 PNG |
| H05 | 领口/肩袖结构 | H01 裁切 |
| H06 | 三分之二侧身 | 银河前片效果 |
| H07 | 街景穿着场景 | 同套摄影语言 |
| H08 | 穿搭展示 | 白色款全套 |
| H09 | 六色汇总 | 六张 SKU 母图排版 |
| H10 | 备用首图（构图不同，非裁切） | 同套 |

生成时**每次实际附参考图**：生产 PNG、银河前后效果、爆款首图。不得只在提示词里写文件名。

### 4.2 详情（**1:3，1080×3240**）——四版式固定

平台详情图只接受 **1:3**。母版按 **9 段 × 1080** 排（1080×9720），再按 3 段一切，
得 **3 页 1080×3240** 上传页。四版式已于 2026-11-02 定稿，只用这四版，不再新增。

| 版 | 代号 | 语言 | 适用 |
|---|---|---|---|
| A | `editorial` 米白杂志 | 左对齐、大留白、金色短下划线、8–10px 细线分隔 | 现行基准版，稳 |
| B | `oscuro` 暗黑高奢 | 通栏满幅、金字居中轴线、章节标题居中、工艺三竖幅满高 | 宗教图最搭，客单感强 |
| C | `bloque` 电商色块 | 黑条+编号 01–07、白底卡片描边投影、红色强调、色卡带色点 | 转化型，信息密度最高 |
| D | `collage` 拼贴杂志 | 宝丽来斜贴 −3°/+2.5°、竖排标签、错位叠图、手写下划线表 | 实拍开箱味，比 A 活 |

九段顺序（四版共用骨料，允许各版改图文关系，不改段落清单）：
首屏(×2 段) / 卖点 / 正反 / 图案 / 面料+规格 / 工艺 / 六色 / 尺码+洗护。

**色卡硬规则**：六色格必须整件平铺（contain）铺在底色上，**不得 `cover` 裁到图案中央**，
否则六个颜色看起来是同一张耶稣脸。工具已验证此点。

**生成与自检**

```bash
python3 tools/pod/listing/make-detail-variants.py --spec <spec> \
    --variant {editorial|oscuro|bloque|collage} --out <png> --split-1x3 <dir>
python3 tools/pod/listing/check-detail-layout.py --spec <spec>   # 必须 RESULT: PASS
```

自检抓三类缺陷：文字越出左右 24px 安全边、两块文字重叠 ≥25%、正文压到 y=9590 页脚线。
不过不自检，不出片。

E–H（技术档案/海报/马赛克/竖排分栏）为结构试验，已移入 `未采用-结构试验/`，**不参与交付**。

九段与三页的对应：

| 页 | 段 | 内容 |
|---|---|---|
| P01 | 首屏(2160) + 卖点 | 模特主图、品名、一句话卖点 |
| P02 | 正反 + 图案 + 面料+规格 | 前后片、印花微距、**服装档案**（面料/克重/成分/领型/袖型/版型）+ 洗护 |
| P03 | 工艺 + 六色 + 尺码 | 领口/袖口/下摆特写、六色、尺码表 |

服装档案段必须出现：面料特写图、规格表、洗护要点。工艺段必须出现领口/袖口/下摆三处特写。
面料与工艺特写由 AI 按本款真实衣色与结构生成，只表现现有结构，不编造刺绣、加厚等工艺。

旧的 6 页生成器 `make-detail-1x3.py` 已被版式引擎取代，保留但不再作为标准产出。

### 4.2b 面料库（AI 细节图的参考源）

`.local/pod-fabric/` 存一号厂 12 张真实胚衣实拍（六色正反，SHA 已核验）与每张切出的纯面料切片。
生成面料/工艺细节图时**必须把对应颜色的 `fabric/<Color>-front.jpg` 作为参考图实际附上**，
不得让模型凭空想象织纹。颜色以库内西语名对齐：Negro / Blanco / Azul / Rojo / Verde / Rosa。

重建：`python3 tools/pod/listing/build-fabric-library.py --out .local/pod-fabric`

### 4.3 SKU 母图

- 每个启用颜色 **1 张**，同色四码复用。
- 母图取本款银河对应色真实效果，统一裁切 1080×1080。
- 颜色只取一号厂六色；六色展示 ≠ 六色全开卖，按实际启用色绑定。

### 4.4 尺码图

衣款级共用件（MXTMC001 S–XL），含肩宽/胸围全围/衣长/袖长，注明测量口径。

## 5. 上架

### 5.1 自动段（已验证）

- 批量表 9 图槽：标题、描述文本、类目、品牌、包裹、价格、库存、商家 SKU。
- 图走自有图床 `img.bri-king.com`，平台导入时自行抓取转存。
- 页面预检 → 导入 → 按款号逐款读回商品 ID 与状态。
- 已验证：单批 20 款稳定；300 款当日发品上限跑满。

### 5.2 详情插图（机制已验证，稳定性待加固）

- 批量表**没有详情图列**，详情 5 张必须进商品编辑页的富文本描述编辑器。
- 已验证：向 `[contenteditable]` 注入带 File 的 paste 事件，图片会上传到平台 CDN 并插入正文（实测 1080×1350 落库）。
- 已知问题：编辑器存在双粘贴处理器，单次注入会插两张；且连续注入后处理器失效，需重新加载页面。
- 当前结论：**可做，但还不能称为全自动**。加固方案是「每张图前重新加载编辑页 → 注入一次 → 去重 → 保存」，需在 5–10 款上验证通过后才纳入自动段。

### 5.3 收尾

- 保存 → 关闭 → 从列表重开 → 核对主图、SKU、价格、数量、包裹、详情。
- 单次提交，独立读回在售状态。
- 平台真实 SKU 回银河做销售 SKU 关联，保存重开逐行核对。

## 6. 分工与闸门

| 阶段 | 产出 | 放行条件 |
|---|---|---|
| 采集 | 爆款档案 + 首图原图 | 有实际图片文件与指标 |
| 生产图 | 前后 PNG + SHA | 可解码、有 alpha、来源绑定 |
| 银河 | 六色设计 + 效果图 | 保存并重开读回 |
| 视觉包 | 10 主图 + 5 详情 + 6 SKU 母图 | 逐张自检：图案/印位/衣色/文字/无重复 |
| 上架 | 商品 ID + 在售读回 | 平台读回，非本地回执 |
| 关联 | 逐 SKU 映射成功 | 保存重开后逐行核对 |

**不得**把本地文件齐全、HTTP 成功、页面预检通过当作全流程完成。

## 7. 数量与裂变比例

- 首批 100 款取自 EchoTik T恤类目。
- 榜一裂变 10 款，其余按 5 款一组裂变，整体 2–3 成做裂变。
- 每款都走完整六色视觉包，不缩减。

## 8. 当前已知缺口

1. 182 款银河只做了黑白两色，需补建四色。
2. 详情插图自动化的稳定性未验收。
3. 生产图长边普遍 1024–1536，非 4K。
4. 模特图为生成图，非银河实拍。
5. SKU 母图当前是银河效果裁切，非纯平铺白底。
