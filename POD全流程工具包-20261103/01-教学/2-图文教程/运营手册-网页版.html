POD员工电脑运营手册

培训日期：2026年10月26日。编制日期：2026年10月25日。内部双线培训版，适用于墨西哥 TikTok Shop 的T恤与手机壳业务。第1至4节是共用基础，第5至9节讲T恤操作，第13节完整讲手机壳操作，其余章节讲共用的营销、订单、异常和考核。

培训目标：新人知道每一步在哪个系统做、依据什么填写、怎样检查结果、什么情况交给负责人。第一天先独立完成商品资料检查和模拟填表；真实后台写入由负责人指定对象并带教。发布、活动、视频、付款和推厂分别按当日授权处理。

图文阅读方法：本版配8张已检查的历史截图，原有红框帮助认位置；每张图旁边说明本店怎样采用。先读操作步骤，再看图，最后按检查标准复述或练习。截图里的示例店铺、工厂、数据和旧按钮不能直接作为本次操作值；缺少当前截图的环节见第16节。

本手册讲完整业务链，不能代替当天任务单和系统实际状态。商品录入、银河设计、工厂映射已有项目操作记录；真实订单、生产、物流、售后和到账在本项目尚未形成完整闭环，相应章节用于讲解核单与验收，首次真实执行须带教。本文不宣布任何现有商品仍是草稿，也不将旧教材中的价格、数量和尺寸作为当天默认值。

2 每天上班先做这五件事

  1. 领取当天任务。 写清店铺、产品类别、商品包、目标商品或草稿ID、允许动作、完成时间和复核人。没指定目标，先做本地资料检查，不在后台随便选一款修改。
  2. 打开对应站斧窗口。 对照窗口名进入现有卖家标签，看店名和墨西哥站点。页面与任务不符，先停。
  3. 看现有对象。 在商品管理用任务中的ID或唯一SKU查找，确认它已经在售、审核中还是草稿。已有对象从原对象继续；不要再点新增制造重复商品。
  4. 打开批准的商品包。 生产图、商品图、SKU图、尺码表、西语文案、SKU映射和成本依据是否齐全；有缺项先列出。
  5. 检查当天异常。 订单发货期限、退款请求、断码、审核失败、工厂延迟优先处理。时限按当前后台实际显示，不按旧教程固定天数。

3 选品和收集参考

打开哪里： 使用负责人已经指定的选品来源、榜单或商品链接，不临时开通付费工具。

怎么做：

  1. 打开参考商品，先看是单件还是套装、T恤还是其他服饰、哪个国家和币种。把商品链接和ID记进参考记录。
  2. 记录主题、领型、袖型、前后印花位置、颜色、售价、统计周期、数据采集时间，以及能观察到的评论问题。
  3. 对照本厂款式。MXTMC001的面料、版型、工艺来自本厂资料；参考商品写纯棉、水洗、反光或速干，不能直接复制到本款。
  4. 参考标题只用于理解表达，改写成自己商品的西语标题；参考销量不能写成自己商品的销量。
  5. 将参考图与可生产原图分开放。没有明确可用依据的图案先交设计和负责人处理，不把竞品图直接当生产文件。

做完检查： 一条参考能找到原链接、日期和商品类型；准备采用的图案有明确版本与可用依据。找不到的数据写“未取得”，不能填0。月销量、周销量和累计销量不放在一起相加。

4 上品前先检查完整商品包

运营负责检查和使用批准文件，生产图修复、去底、高清增强和复杂排版由设计或负责人指定的工具完成。AI产出先审阅，不能直接上传。

文件 人工检查方法
生产原图 打开原件，确认图案、版本、透明背景、前后印面；不带模板线或展示背景
商品主图 看整件款式、颜色、印位和图案是否与生产图一致，无错字、水印或额外商品误导
详情图 放大读文字，确认成分、包含件数、正反面和护理内容真实
SKU图片 按颜色逐张比对，不能黑色变体配白衣图；只有尺码不同可用同款同色图

图案一致性检查： 先看生产图，再看主图和SKU图，比较人物或文字、图案颜色、正反面以及图案占衣身比例。展示图把印花放得很大、生产模板却很小，也应退回修正。

本批资料和素材先检查通过，再进店铺填表。不能填一半才临时生成缺图，也不能把新图直接覆盖到已接单的旧生产版本。

5 T恤在银河设计中检查生产图

打开哪里： 打开已登录的银河设计页面，从负责人给的设计任务或设计列表查找当天对象。菜单名称有变时按页面实际功能定位；没有确认对象前不点新建。

怎么做：

  1. 打开目标设计，核款号MXTMC001、工厂、设计名称和版本。已有设计优先重开检查，创建新版本由负责人决定。
  2. 找到颜色和尺码选项，仅保留本次批准的可售组合。系统模板额外显示的颜色或尺码，不能自动算本厂可供。
  3. 选择前片或后片，按文件用途上传或选用生产原图；主图、模特图、尺码图不用于印花文件。
  4. 锁定图案宽高比例，按当前尺码模板设置大小和位置。先看印区边界，再看整衣预览；不拉伸图案，不用一组旧厘米数套全部尺码。
  5. 逐色、逐码、逐面检查：图案完整、位置正确、没有裁切和白底残留，清晰度提示及实际像素可核。前面通过不能代替后面通过，L码通过不能代替S码通过。
  6. 记录设计ID、生产图版本、每面实际尺寸和异常。具体参数使用当天批准表，36×56cm或S约80%等旧规则不能直接代替当前模板实测。
  7. 获得本次保存权限后，点击正常保存，等加载结束；退出详情再从列表打开同一设计，核颜色、尺码、印面、图案和参数是否保留。

做完检查： 能通过任务ID重新找到设计，实际拟售组合逐项对应。界面预检与实物打样分开；清晰度、印区或价格有疑问时不自行写“合格”。

6 在卖家后台填写商品

6.1 进入正确对象

  1. 打开对应站斧店铺，进入卖家后台的“商品 → 商品管理”。
  2. 已有商品或草稿：按任务ID定位，打开原对象的编辑入口。教学示例ID只用于识别，不作为允许修改的清单。
  3. 仅在负责人确认这是新商品时，使用“添加商品 → 添加单个商品”。
  4. 编辑前记录当前ID和主要内容；其他人正在编辑同一对象时先协调，不能同时保存。

6.2 基本信息与属性

  1. 上传图库。 按批准顺序选主图和细节图，等待每张上传完成。检查后台当期文件格式、大小、像素和张数限制；文件夹里的20张候选图不要求全传。
  2. 填写标题。 使用批准的墨西哥西语标题，写清实际商品和主题。单件不要写套装，不堆无关品牌或功能词。
  3. 选择类目。 按实际商品选择T恤对应类目；AI推荐后仍要人工核对。品牌按真实情况选择后台提供的无品牌或实际品牌，不造授权。
  4. 填写属性。 MXTMC001的教学事实为180G CVC、50%棉50%涤、圆领短袖，执行前对照当天款号资料。不能因为旧截图材质选涤纶，就照着选择。
  5. 写商品详情。 贴入批准的西语文字，添加本款详情图和适用通图。等待编辑器加载，点到编辑区以正常方式粘贴，完成后点击其他区域让内容更新。

6.3 颜色 尺码和SKU

  1. 在“销售信息”添加或核对颜色和尺码两个变体维度。颜色采用批准的西语显示名，例如Negro为黑色、Blanco为白色。
  2. 按当天可售表加入实际尺码。只有黑色S/M/L/XL时是4行；批准六色六码且全部可供、路由齐全时才可能是36行。不能把设计模板组合数当可售数量。
  3. 每行上传或选择对应SKU图，再核图片颜色和图案；主图库有图不等于SKU行已关联。
  4. 从批准映射表复制每行商家SKU。不要让多行使用同一编码；平台长ID和商家自编SKU分别保存，复制时避免表格显示成科学计数法。
  5. 从批准价格表填写售价，确认币种MXN；可售数量来自胚衣可供、产能和履约时间的额度依据，不能统一填999或1000。
  6. GTIN、免码、合规等字段按平台真实选项和实际资质处理；不知道时记录问题，不编条码或上传无关证明。
  7. 上传批准尺码图，并核后台原生尺码表。已有结构表不要因旧教材只用图片就删除；数字、单位和胸围量法要一致。

图3怎样做： 找到“添加销售变体”，分别核颜色和尺码维度。图中Negro、Blanco帮助识别黑白西语名；图里的XXXL、XXXXL等选项不是本次可售批准表。按当天批准组合核行数，不复制整张列表。

图4怎样检查： 逐行看左侧缩略图、颜色和尺码是否对应，再核本行商家SKU、批准售价和可售额度。图中1000库存、198价格和180克均为旧例，禁止直接批量应用；“更多批量选项”只在目标行和字段已经逐项复核后使用。

图5怎样检查： 上传自己的批准尺码图后，逐格核自动识别结果，再对照原生结构表。图中“100% Poliéster”和各码数字不适用于本款CVC，图片中的1—3cm公差也不能当成本厂保证。

6.4 物流和包裹

  1. 查看单位选择，分别确认重量是g、kg还是lb，长度是cm还是in。
  2. 按本款实际含包装记录填写重量、长、宽、高；衣服180g/m²是面料克重，不能作为包裹重量。
  3. 包裹参考值只能按批准的适用范围使用。未测得的数值先留待核，不把所有款、所有码设为教材中的固定值。
  4. 核发货仓、退货仓和物流模式是否属于当前店铺与工厂。仓库已绑定就核对，不重复改仓。
  5. 费用和买家承诺按当前实际配置确认，不凭后台一个0值就承诺包邮或免费。

7 保存后重新打开检查

这是员工必须掌握的一步：填完不算完成，能重开读到正确内容才算保存检查通过。

  1. 等所有图片上传结束，点击一次“另存为草稿”或当前对象的正常保存入口，等成功提示和加载结束。
  2. 记录商品或草稿ID，返回“商品管理”，从列表重新打开同一个ID。不要为了检查而新增一个商品。
  3. 从上到下检查图库张数和顺序、标题、类目、属性、详情文字和图片、颜色尺码、每行SKU图和编码、价格、数量、尺码表、物流。
  4. 描述区未显示时滚到该区域等待编辑器加载；不能瞬间看不到就断言内容丢失。
  5. 切换颜色和尺码查看消费者预览，确认图片与选择一致、文字可读、包含件数明确。
  6. 发现差异，回到同一对象修正并重复保存检查。保存超时或结果不明，先回商品列表查一次，不连续点保存或重新建品。
自检项目 员工应能回答
对象 我重新打开的是哪个ID？
图片 主图、详情和各SKU图分别有多少，是否逐张正确？
变体 哪些颜色和尺码可售，实际有多少行？
字段 哪些值与批准资料一致，哪些仍待核？
结果 是保存了草稿，还是已经提交审核？证据在哪？

8 关联工厂和逐SKU映射

T恤操作：

  1. 在RIIN已有店铺商品或关联商品入口查找准确平台商品ID，核店铺与款式。
  2. 使用页面已有的“关联本地设计”或对应正常关联功能，选择准确的银河设计版本；不能只看缩略图相似。
  3. 按商家SKU逐行核颜色、尺码、印面、工艺和工厂款号。页面名称随版本变化时，先核功能和目标，不靠猜测点击。
  4. 对照批准表检查真实产品编码；所有实际销售组合都应覆盖。找不到或有两种匹配时停该行，不自行替换设计或工厂。
  5. 在本次映射保存授权范围内保存，关闭明细后重新打开，逐行查到关联结果。若保存动作会同时扣款或推订单，先停并交负责人。
  6. 保存映射记录到原商品包；自动付款、自动推厂等设置不因映射完成而开启。

做完检查： 店铺商品的每个可售SKU能唯一找到工厂变体和准确生产版本。列表提示成功、设计存在或编码看着完整，都不能代替重开逐行检查。

9 商品提交 审核和买家页面

  1. 员工完成第4至8节检查，将待发布商品ID、变体数量、价格、供货依据、费用表和保存检查交负责人复核。
  2. 负责人确认这次允许的商品、动作和数量后，再按正常入口提交。手册不能给员工增加发布权限。
  3. 提交后在商品管理记录真实状态：审核中、失败、在售或其他当前状态。成功提示不能直接记成买家可购买。
  4. 审核失败先打开具体原因，定位哪一项需修正，再处理原商品；不复制新链接躲过问题。
  5. 对应商品在售后，打开真实买家链接检查标题、颜色尺码、图片、售价、运费与承诺时间。验证控件可用即可，不为培训创建订单。

状态要分别记：资料齐全、设计已保存、映射已保存、草稿已保存、审核中、在售、买家端已核。商品发布不证明已经生产、发货或赚钱。

10 活动和视频怎样培训

这一节先教入口和复核方法。旧教材中的一口价79.99、满100减10、活动固定10天、每天3条视频均不是本店默认方案；当前界面和资格需在实际店铺重新核对。

商品折扣和优惠券

  1. 在卖家后台“营销 → 营销活动”查看当前可用工具；旧教程有商品折扣和优惠券入口，实际名称以当天页面为准。
  2. 新建前先查看是否已有活动及时间重叠，避免重复折扣。确认活动对应的时区、开始结束时间、商品范围和卖家承担金额。
  3. 先算折后收入，再核平台费、达人佣金、卖家券和履约费用，取得批准的最低成交价和预算。
  4. 如果获准创建，在设置页逐项核对范围：指定商品与全店不是一回事；某些券可能覆盖更多商品，不能照着教程全店勾选。
  5. 到最终预览页暂停复核，确认本次发布授权后才提交；提交后重开活动，检查生效时间、商品和优惠是否正确。

带货视频

  1. 用已批准的商品资料写脚本，画面中的款式、图案、颜色和售价与实际商品一致；不伪称实物测评或承诺未经验证的功能。
  2. 生成或剪辑后完整播放，检查西语、字幕、音乐使用范围和展示商品。付费生成先确认预算。
  3. 旧教程入口为“直播和视频 → 带货视频 → 发布视频”；进入实际页面后先确认账号和功能资格。
  4. 上传批准的视频，在“添加商品”中选择准确商品ID和链接，逐项核文案、话题、商品卡与发布账号。
  5. 负责人批准本次视频发布后再提交；之后检查实际视频页和挂载商品。商品发布批准不自动包含视频发布或广告投放。

11 真实订单 生产 物流 售后和到账

本节为首次真实订单的带教清单。没有订单时用脱敏样例讲核对方法，不下测试单、不付款、不推厂。不同履约模式的具体按钮和副作用，由负责人在首次真实单中确认后补入对应业务SOP。

订单审核

  1. 在当前店铺订单管理查真实订单，核付款状态、取消状态、商品ID、行项目、颜色尺码、数量和平台发货截止时间。
  2. 用店铺＋订单ID＋行项目及已处理数量判断是否处理过；多次同步、部分发货和补发不能造成重复生产。
  3. 按订单SKU查唯一映射，再核工厂款号、图案版本、印面和实际可供。不能凭标题或缩略图猜款。
  4. 地址异常或订单备注影响生产时，在原系统处理并交复核；客户地址和电话不复制到普通培训笔记。

付款 推厂和生产

  1. 准备待处理订单、件数、工厂、生产图、报价及预计交运时间，核是否处于具体付款与生产授权范围。
  2. 首次操作由负责人带教，弄清按钮是否连带扣款、锁单或立即进入生产；副作用未确认前不点。
  3. 成功后查真实工厂单号、接单状态、实际扣款和排期。请求成功或页面提示不等于工厂已接单。
  4. 操作超时先查原单和扣款结果，不能重复推送。缺货或改图需重新确认，不自行换颜色、换厂或换设计。
  5. 质检核图案、印面、大小、衣服色码、数量和污损，预览图不能代替实物检查。

面单 交运和物流

  1. 核平台订单与包裹、面单和承运方式一致，重量和尺寸来自实际包裹。
  2. 生成面单、工厂打包、交给承运商和承运首扫分别记录。仅有单号或ERP回填，不能记成承运已揽收。
  3. 追踪第一次有效扫描及后续运输，临近平台期限仍无进展时交负责人处理；不伪标发货。
  4. 妥投按真实物流状态与必要凭证记录；异常件关联原订单跟进。

售后和对账

  1. 在平台售后入口查看原因和响应期限，关联原订单、商品、质检及物流证据。
  2. 退款、补发、退货和工厂赔付分别确认权限及金额，不为结案随意承诺。补发要关联原单且防重复生产。
  3. 在平台资金或结算入口查看订单账单，与工厂实扣、物流费用、退款和实际到账核对；不以账户余额变化代替逐单结算。
  4. 费用统一币种和作用域，已包含的项目不重复扣。未取得的费用留“待核”，预估贡献和实到账净利分开。
  5. 结案至少能串起真实订单、工厂单、生产质检、首扫、妥投或售后、平台结算和到账；没有的节点保留未完成。

13 手机壳完整电脑操作流程

手机壳单独演示一款商品，员工单独交一份练习结果。共同的登录、保存重开、订单去重和异常上报方法仍按前文执行；商品事实、机型、图编和多鸿映射使用以下独立流程，不能套T恤成衣尺码或银河设计。

13.1 进入手机壳店铺和资料库

  1. 在站斧打开负责人指定的tk-uump1694窗口，核卖家后台店名MARART、墨西哥站及当天目标ID；不要在tk-xjcx4623里录手机壳。
  2. 从项目“手机壳 → START-HERE”打开手机壳资料库，或打开负责人提供的现有资料库阅读页。按材质选择表，再查精确型号和颜色。
  3. 将目录原文、型号、颜色、状态和来源表/单元格记入原商品包。空白表示未知，“暂无/停售”不能改成可售，目录存在不证明当天有货。
  4. 同名型号如有4G/5G、地区或代际差别，要按本材质的实际对应表确认。保护膜、配件和平板的兼容表不能代替手机壳表。

检查结果： 员工能指出这个壳是什么材质、给哪一个精确机型、哪种颜色、在哪一张原表找到。不能回答就暂不进入上品。

  1. 打开候选参考和本店可用生产原图，确认图案版本及可用依据；参考截图仅用于学习，不自动拿去印。
  2. 打开这一个材质、机型、颜色和工艺对应的底壳模板，核镜头孔、按键、安全边和印区尺寸。
  3. 比较生产图与效果图：图案方向、位置、颜色和开孔避让一致。带手机、手、阴影和宣传文字的商品效果图不能当工厂生产原图。
  4. 缺真实模板时列出缺口，不靠AI补造镜头孔；没有工厂或产品证据的磁吸、防摔、抗黄变性能不写入卖点。

检查结果： 每个拟售机型有明确底壳和文件对应；不是拿一张iPhone图片就宣称所有手机通用。

  1. 按材质、工艺分别整理生产原图和效果图，保留批准版本；商品主图、详情、参考图另放。
  2. 准备清晰单壳主图、图案细节、材质结构、精确机型选择和包含物说明。没有包含挂绳、膜或礼盒的单壳，图片和文案不能让买家误以为包含。
  3. 按同一批准商品事实准备墨西哥西语标题、详情、颜色和型号名称，不残留中文、竞品店名或T恤描述。
  4. 为每个真实销售组合准备一行映射：材质、系统型号、平台显示型号、颜色、短SKU、工厂码、图编、生产原图、图片、售价、可供依据和包裹来源。
  5. 按第4节检查本批所有素材并冻结。不同背景的候选图不自动成为多个独立商品链接，商品身份和机型变体由负责人确定。

检查结果： 没缺图、没错孔位、没错型号，SKU表中每行能找到本款生产图和展示图。先完整备好，再进卖家表单。

14 明天怎样培训和验收

两条都培训，建议安排240分钟教学与练习，另加休息；可拆成上午T恤、下午手机壳。每条业务各拿一个已批准资料包，员工分别完成练习，不能只听一遍就视为两条都掌握。

时段 讲师演示 员工练习
0—25分钟 共用基础：两店、两工厂、文件分类、任务和权限 区分两条路线，指出各自窗口、系统与不能混用的字段
25—50分钟 T恤资料包、生产图、银河色码与印面 按批准表核色码和图案版本，找出错色、缺图或错误印位
50—95分钟 T恤表单、SKU、保存重开、RIIN关联 独立完成T恤模拟填表，反查两个不同色码SKU；真店写入另行指定对象
95—120分钟 手机壳资料库、材质表、机型模板和孔位 找到一个精确机型，指出来源表、底壳、颜色与图案
120—165分钟 手机壳表单、短SKU、图编和多鸿映射 独立完成手机壳模拟填表，反查两个机型；识别导入成功但查询0的失败情形
165—195分钟 活动、视频、订单与生产到结算 用两类脱敏样例核订单、生产版本、首扫与到账证据
195—225分钟 双线独立考核与跨店错误排查 分别交T恤和手机壳检查结果，指出故意混入的工厂、SKU或包裹错误
225—240分钟 讲师复核、纠错与接续 两条业务分别记录缺项、下一步和复核人

模拟填表清单

在练习副本填写，不把练习值导入真店：店铺、商品类别、商品包、目标ID、标题、类目、品牌、材质、主图顺序、详情、颜色尺码/机型、每行SKU与图片、售价币种、可售数量依据、尺码表或模板、包裹、工厂设计/图编、缺项和复核人。值必须从负责人给的案例资料找，不由员工猜。

员工通过标准

  • 已分别完成1份T恤和1份手机壳练习，缺项分别列出。
  • T恤能反查2个不同色码SKU；手机壳能反查2个精确机型，不串用工厂与编码。
  • 能进入正确店铺并按ID找到指定商品，区分草稿、审核中、在售。
  • 能分清生产原图、商品主图、SKU图和详情图。
  • 能按批准表核颜色尺码/机型、唯一SKU及对应工厂文件。
  • 知道价格、数量、包裹和面料字段分别从哪里取值。
  • 能说明保存后为什么要退出重开，以及怎样判断内容一致。
  • 遇错店、缺图、重复编码、保存未知或映射查不到时会停并描述问题。
  • 能区分有单号、有效首扫、妥投和真实到账。
  • 知道哪些动作可以独立做，哪些必须由负责人指定和复核。

第一天通过基础检查后，先独立做资料检查与异常记录。独立保存商品、发布、活动、视频、订单和付款的权限逐项确认，不以一次培训勾选自动取得所有权限。
