ZCode 交接文件是恢复说明，不是运行中的执行器。不得在本任务中操控 ZCode，也不要把“提示词包已交付”误写成“ZCode 已启动”。新电脑的真实工具、浏览器会话、扩展和图像能力必须现场核验。来源：[T恤 ZCode README](../project/T恤/ZCode工作流/README.md)、[T恤交接惯例](../project/T恤/ZCode工作流/03-交接规范与模板.md)、[手机壳 CURRENT](../project/手机壳/ZCode工作流/交接-CURRENT.json)。

## 2. 迁移边界与私有仓库

用户要求把 POD 业务资料上传到私有 GitHub，并在新电脑恢复为 `project/`。本次只读 `du -sh` 盘点显示源目录约 6.6 GB，其中手机壳约 2.5 GB、`output/` 约 3.5 GB；大文件需要使用仓库实际支持的大文件方案或私有制品存储，不能把 GitHub 普通 Git 文件限制当成“无法迁移”的结论，也不能为了缩小体积删除原样资料。来源：[手机壳工作簿](../project/手机壳/hack.xlsx)、[手机壳当前交接](../project/手机壳/ZCode工作流/交接-CURRENT.json)、[T恤交接规范](../project/T恤/ZCode工作流/03-交接规范与模板.md)。

仓库不得包含密码、验证码、Cookie、Token、浏览器 Profile、登录会话、私钥、客户明细、订单个人信息、运行中的锁文件、缓存和临时上传快照。完整业务原图和私有访谈资料可以进入私有包，但应按敏感资料管理；公开仓库、公开 Issue 和示例文档不得复制这些材料。来源：[根规则](../project/AGENTS.md)、[T恤 ZCode 交接边界](../project/T恤/ZCode工作流/03-交接规范与模板.md)、[访谈包隐私说明](../project/output/pod-final-delivery-20261018/POD完整方案与18段访谈复盘-20261018/README.md)。

迁移包还必须保持两边技能、相对链接、manifest、图片、ZIP/TIFF/PSD 与证据之间的可解析关系。只复制 Markdown 或只复制图片会让新电脑无法恢复生产对象。源目录和迁移包验收应分别检查文件存在性、SHA256、图片解码、HTML 资源、ZIP 完整性和相对链接。来源：[T恤批次 manifest](../project/T恤/批次/B20261023-SJBLUE-01/manifest.json)、[手机壳商品包](../project/output/mx-phonecase-catalog-20261023/packages/first-DFBLK10HS01145/manifest.json)、[迁移包目录](业务与记忆接续.md)。
