# POD 定价流程（锁定 v1.1.0）

锁定日期：2026-11-04。政策源：`config/pricing.json`。改政策必须改这个文件并升版本，不要在命令行临时漂移。

## 口径

| 项 | 锁定值 |
|---|---|
| 固定服务费 | 6 MXN，**按件**（2026-07-06 起；3 件订单扣 18） |
| 运费 | **0**（工厂墨西哥直发，无头程；墨西哥本地配送由 SFP 覆盖） |
| 目标余量 | 每单 1–3 元人民币，落点 2 元 |
| 售价取整 | 向上取整到 1 MXN |
| 佣金 | 售价 × 6% |
| SFP | 售价 × 8%，每件封顶 40 MXN（2026-06-22 起） |
| IVA 代扣 | 售价 ÷ 1.16 × 8% |
| ISR 代扣 | 售价 ÷ 1.16 × 2.5% |
| 汇率 | 0.36 CNY/MXN（2026-11-10 校正） |
| 成本 | `data/costs/latest.json`（银河报价快照） |
| 市场 | `data/market/<week>.json`（EchoTik Top100） |

可变费率合计约 **23.05%**，另加 **6 MXN/件**。单件售价反解：

```
售价 = (成本CNY / 0.36 + 6 + 目标余量CNY / 0.36) / (1 - 可变费率)
```

## 免运费到底免给谁

TikTok Shop 墨西哥的 SFP（Programa de Tarifa de Envío）是自动加入的：

- 订单包裹 **<3kg** 且符合条件时，**TikTok 承担全部运费，买家免运费**；
- 卖家不付这段本地运费，付的是 **售价 8% 的 SFP 服务费**（每件封顶 40 MXN）；
- 包裹 >3kg 时，超出部分默认由买家承担；卖家可以选择自己承担，换取商品页的“Envío gratis”标识。

所以：**“免运费”是免给买家的，不是卖家零成本。** 卖家的物流成本是 8% SFP，不是那笔 59/69 MXN 的运费。

工厂**墨西哥直发**，没有中国→墨西哥的跨境段，因此不存在头程；2026-10-21 的跨境运费拆分对直发工厂不适用。墨西哥本地配送在 SFP 内由 TikTok 承担（<3kg），卖家付 8% SFP；`shipping` 锁定为 0。

## 一条命令跑完

```bash
node cli.mjs flow --batch <批次目录> --refresh-costs --save
```

- `--refresh-costs`：从银河重新读报价并写 `data/costs/latest.json`（需要 Chrome 9222 且已登录银河）
- `--save`：把整批结果写 `<批次>/pricing-flow.json`
- 退出码 1 = 有亏损或缺价 SKU，停止上架

## 五步链路

```bash
# 1. 成本：银河报价快照
node cli.mjs riin --save

# 2. 市场：EchoTik 周榜价带
node cli.mjs market --market <rankings.json>

# 3. 定价：按锁定口径写回 listing-spec.json
node cli.mjs apply --batch <批次> --apply

# 4. 门禁：亏损/缺价/偏离目标
node cli.mjs audit --batch <批次>

# 5. 上架：出表 → 页面预检 → 导入
node <pod-image-listing>/scripts/listing-step.mjs check --spec <spec> --prefix <款号>
node <pod-image-listing>/scripts/listing-step.mjs publish --spec <spec> --apply
```

## 审计标记

| 标记 | 含义 | 处理 |
|---|---|---|
| `BELOW_BREAKEVEN` | 扣完所有费用后亏钱 | 必须改价，退出码 1 |
| `NO_PRICE` | spec 没有价格 | 必须补价，退出码 1 |
| `BELOW_TARGET` | 余量低于 1 元 | 上调或降成本 |
| `ABOVE_TARGET` | 余量高于 3 元 | 起量阶段通常还能降 |
| `COLOR_PRICE_LEAK` | 彩色款卖得 ≤ 黑白价，但成本高 3.5 元 | 彩色加价 |
| `ABOVE_MARKET_P90` | 高于市场 90% 的同类 | 转化风险 |

## 改口径的唯一方式

编辑 `config/pricing.json`：

- 确认工厂另收本地出库/快递费：把 `"shipping"` 改成实际比例；没有就保持 0；
- 如果平台恢复按单收费：`"fixedScope": "order"`；
- 如果换汇率/费率：改对应字段；
- 每次改动把 `version` 加一、更新 `locked_at`，然后重跑 `flow`。
